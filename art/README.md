# Squeek Delve art

All game pixel art is code in `delve.px.js` (pxl DSL: one 30-color palette, light from the top-left, characters face right). To rebuild, run `node /tmp/skills/pxl/pxl-pixel-art/bin/pxl.js build art/delve.px.js` from the repo root. Output goes to `art/out/` (the sheet is `out/sprites.png` and `out/sprites.json` in TexturePacker hash format, the title is `out/scenes/title.png`, and upscaled previews are in `out/_preview/`). Then copy the final files into the game: `cp art/out/sprites.png art/out/sprites.json web/assets/ && cp art/out/scenes/title.png web/assets/title.png`. The hero fur uses exactly `#E8B07A` / `#C98A54` / `#8A5A34` so the game can recolor it at runtime, so don't reuse those hexes anywhere else. The `tiletest` scene is only there to check tile seams and is not part of the sheet.
