# Squeek Delve art

All game pixel art is code in `delve.px.js` (pxl DSL: one shared palette, light from the top-left, characters face right). To rebuild, run `node <pxl>/bin/pxl.js build art/delve.px.js`, where `<pxl>` is the [claude-pxl](https://gameskill.dev/skills/claude-pxl) skill (`curl -fsSL https://gameskill.dev/dl/skills/claude-pxl.zip -o pxl.zip && unzip pxl.zip`, Node ≥ 22.18) from the repo root. Output goes to `art/out/` (the sheet is `out/sprites.png` and `out/sprites.json` in TexturePacker hash format, the title is `out/scenes/title.png`, and upscaled previews are in `out/_preview/`). Then copy the final files into the game: `cp art/out/sprites.png art/out/sprites.json web/assets/ && cp art/out/scenes/title.png web/assets/title.png`. The hero fur uses exactly `#E8B07A` / `#C98A54` / `#8A5A34` so the game can recolor it at runtime, so don't reuse those hexes anywhere else.

Tiles come in three biomes, `b0` Topsoil, `b1` Rootclay and `b2` Crystal Deep. Each one has `floor_0..3`, `room_0..1`, `wall_top`, `wall_face_0..1` and `stairs` (for example `b1_room_0`). The sheet also has enemies (`rat`, `mole`, ...), loot (`chest`, `wpn_0..4`, `arm_0..3`, `sl_0..2`, consumables) and 8x8 UI icons. The `tiletest_b0/b1/b2` scenes are only there to check tile seams and are not part of the sheet.
